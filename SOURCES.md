## Adaptations

The skill keeps broadly useful ideas: understand the brief and context; inspect existing code and design systems; establish deliberate visual rules; preserve supplied copy; scope implementation; use responsive and accessible patterns; and review actual rendered results when possible. It deliberately makes exploratory directions optional and limits them to exploratory asks, and makes seeded random exploration optional. It treats typography and color choices as contextual, rather than prescribing a universal aesthetic. Contrast guidance follows commonly used WCAG thresholds; target dimensions and slide/print sizes are presented as heuristics with context. Rendering is encouraged when tools exist, with explicit disclosure when it cannot be verified.

Environment-specific commands, private tools and identifiers, fixed interaction scripts, and instructions that assume a particular runtime were excluded. The package is runtime-independent and does not require a particular browser, framework, image tool, or filesystem layout.
